## About

Traveling&YOU helps a visitor choose a holiday by the kind of trip they want rather than by destination — the entry point is "what type of traveler are you", not "where do you want to go".

## Features

- **Trip category grid** — culture, cruise, nature, beach, city break, history, family and winter
- **Mobile app promotion** with a feature list: offline maps, self-guided schedules, skip-the-line booking, nearby attractions
- **Customer reviews section** — six testimonials with star ratings, reviewer initials as avatars, destination labels and expandable text
- **Adventure activities** — carting, kayaking, paragliding, diving
- **Classic destinations** — Paris, Los Angeles, Tokyo, London
- **Featured destinations** with descriptive write-ups for Osaka, Santorini and Barcelona
- **Footer** covering hotels, bookings, resources and destinations

## Built with

HTML5, CSS3, Font Awesome (icons via CDN).

## Running locally

```bash
git clone https://github.com/BiancaSud/Project-3-Tourism-Agency-Site.git
cd Project-3-Tourism-Agency-Site
```

Open `index.html` in a browser.

## What I focused on

The reviews section. Each card holds a rating, an avatar, a name, a location and a body of text that varies in length between reviews — keeping the cards aligned in a grid despite the uneven content was the part that took the longest.
